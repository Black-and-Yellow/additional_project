# Project description

**TrustRAG: Uncertainty-Gated Retrieval and Hallucination Analysis**

TrustRAG is a local research application that examines the reliability of language-model answers using uncertainty estimates, document retrieval, and internal model signals. It combines semantic entropy with a fitted context-consistency detector and checks candidate answers against source evidence. The application provides an interactive workspace, guarded answer correction, abstention, and downloadable execution records.

The current evaluation uses controlled fictional documents. It demonstrates a complete experimental workflow while leaving broader factual reliability and the effectiveness of correction open for further study.

**One sentence:** TrustRAG combines uncertainty estimation, document retrieval, and model diagnostics to inspect whether generated answers agree with the available evidence.
