      METHOD & SCOPE

      What the pipeline measures

      01

      Generate and measure disagreement

      The model produces an initial answer and stochastic samples. Bidirectional NLI groups equivalent answers. Empirical cluster frequencies determine entropy in nats.

      02

      Retrieve before inspecting context use

      For uncertain answers, BM25 retrieves local passages. The model generates with that context before attention and residual-stream probes run.

      03

      Intervene and verify

      The fitted detector flags possible context conflicts. Unsupported flagged answers can receive guarded attention/FFN correction. Every sentence must pass the evidence check before acceptance.

      Research scope: the fitted detector uses components selected on training data and a threshold selected on validation data. Separate test groups contain controlled fictional examples. General factual reliability requires broader evaluation.
